caption.js defines a unified, permanent caption-bar system used across all Sketchpad tabs. It is responsible for building, updating, and normalizing the caption area that appears above main content (drawings, patterns, gallery items, etc.).

The caption bar has a fixed layout and behavioral contract that all tabs must follow. This file enforces that contract so individual tabs do not reimplement caption logic or manipulate caption DOM elements directly.

Permanent caption layout

  • Left side: Title
    The title is always left-aligned and takes flexible width.

  • Right side: Button cluster
    Buttons appear in the following fixed order:

    • Prev (optional)
    • Next (optional)
    • v (menu button — always present)

The caption bar always includes a menu button ("v"). If no menu handler is supplied, the button is disabled and visually dimmed.

setCaptionBar(config)

This is the core builder function. It clears and rebuilds the caption bar from scratch on every call.

Arguments:

  • targetId – DOM element ID of the caption container
  • title – text displayed on the left
  • onPrev – optional callback for the Prev button
  • onNext – optional callback for the Next button
  • onMenu – optional callback for the menu button

Behavior:

  • Fails fast if the target element does not exist
  • Clears any existing content
  • Applies a flex layout with space-between alignment
  • Creates the title span on the left
  • Creates a button row on the right
  • Conditionally adds Prev and Next buttons only if callbacks are provided
  • Always creates the menu button ("v")
  • If no onMenu handler is provided, the menu button is disabled

The caption bar itself does not manage menu behavior. It only provides a button and delegates all menu logic to the caller.

normalizeCaptionEntry(raw)

This helper function produces a predictable caption-entry object regardless of how different tabs represent their metadata.

It allows tabs to pass in loosely structured data without duplicating normalization logic.

Input:

  • raw – an object containing tab-specific metadata (for example a drawRegistry entry, pattern entry, or gallery item)

Output:

  • title – resolved from raw.title, raw.name, or a default
  • filename – copied if present, otherwise null
  • category – copied if present, otherwise null

This function contains no tab-specific logic and is safe for use across all tabs.

buildMenuHandler(tabName, context)

This function constructs a safe, standardized menu-button handler for the caption bar.

It returns a function that, when invoked, calls:

menuManager.open(tabName, context)

This allows each tab to keep its menu wiring extremely small and consistent. Tabs do not need to know how menus are built or displayed — they only provide context.

The caption bar remains ignorant of menu content and behavior.

rebuildCaption(config)

This is a convenience wrapper that clears the caption container and rebuilds it in a single call.

Behavior:

  • Fails fast if the target caption element does not exist
  • Clears existing DOM content
  • Delegates all construction to setCaptionBar()

This function exists to prevent tabs from directly manipulating caption DOM elements, ensuring consistent behavior and layout across the application.

Overall, caption.js enforces a single, shared caption-bar contract for Sketchpad. It cleanly separates:

  • layout (handled here)
  • menu logic (handled by menuManager)
  • tab-specific behavior (provided via callbacks)

This keeps caption behavior predictable, minimal, and consistent across all tabs.
