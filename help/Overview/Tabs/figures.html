Figures Tab — A First Discussion

Written 27 October 2026, after Phase 8 (welds) was merged into claude1. This is a preliminary account: what the tab is for, the ideas it is built on, how it is used today, how the code is laid out, and where the phases stand. The authority for the phases is PHASES.md.

What it is for

Figures is where several drawing objects come together into one design. It serves two purposes, and neither is a means to the other:

  1. A printable point template for pounding nails into wood: every hole numbered and placed, at true size.
  2. A place to sketch: to explore designs by working with how objects are represented and how they relate to each other. The original StringThing could not do this, and it is why the program is called Sketchpad.

When a decision trades one purpose against the other (trimming a control range, dropping an object that nails cannot use, forcing every object through one drawing path), it is raised for decision rather than settled quietly.

The ideas, in the order they build on each other

Figure
One design, in its own subtab ("Untitled 1"). Plain data: name, layers, discs, welds. It lives in uiState.figures.tabs[tabId].figure, so it survives switching tabs. It is not saved to disk yet (Phase 10).
Layer
One inserted registry object (a Line, a Parabola, a Regular Polygon...) with its parameters, a visibility flag, an identity color, and a transform. Layer numbers never change. Stacking order is kept separately; the last layer clicked goes on top.
Instance
The live object that draws a layer: a private copy of the registry object, so two Parabolas do not share parameters. Kept beside the figure, not in it.
Transform
How far a layer has been moved and turned: { angle, tx, ty }. The object keeps its own numbers; only the transform changes. Every drawn line, handle and disc goes through it.
Handle
One of the object's own red dots. The only thing that drags the object's shape. Arrow keys nudge the selected one (1 px, 10 with Shift).
Infrastructure
The skeleton of an object: the lines (arms) the stitches run between, as opposed to the stitches themselves. Each arm is divided into candidate points, the places a disc can sit.
Disc
A numbered point, drawn as a filled circle in its layer's color. Anchored: sits at a fixed fraction along an arm and rides with the object. Free: placed anywhere and moved only by dragging it. Numbers are never reused.
Centroid
The diamond at the center of the active layer's extent. Drag it to move the layer; click it for a box with a rotation handle.
Weld
A group of discs, on different layers (or two corners of one object), that must stay on the same spot. Drag one, and the others' objects follow.

The screen

  • Left column: Commands; Show All (every layer at full strength, hidden ones too); Points Mode; Create Figure (on Categories) or Insert Object (in a figure).
  • Caption bar: the figure's name; Line and Parabola buttons; "Layer N · Name" and its Show checkbox; the "v" menu (Help, Notes, Hit radius, Delete selected point, Break apart, and grayed future items).
  • Layer strip, left of the canvas: one numbered chip per layer, in its color. Click to make it active; right-click to change its color. A hidden layer's number is struck through.
  • Canvas: the layers, the discs, the weld marks; above it the centroid overlay and the handles.
  • Action panel: the active layer's sliders, built by the same code the Draw tab uses.

How it is used today

Lines mode (the default)

  • Insert objects. A second copy of the same object is offset 20 px so it does not land on the first.
  • Drag handles to shape the active object. Drag the diamond to move it; click it and drag the round handle to turn it.
  • Hide a layer while working (it still appears in Show All and the final drawing).
  • Break apart: a composite object becomes separate layers, one per piece. The original is hidden.

Points mode

  • Layers show only their points. Only the active layer can be changed, and the insert tools are grayed.
  • Left-click near a candidate: an anchored disc. Elsewhere: a free disc. On a disc: select it. Drag a free disc to move it. Delete or Backspace removes the selected disc.
  • Right-click on a spot where two discs meet: weld them. Right-click a welded disc: unweld it. A short note in the caption bar says what happened.

Making a weld, step by step

  1. Points Mode on.
  2. Make the first object's layer active and click the meeting spot: a disc on that object.
  3. Make the second object's layer active and click the same spot: a disc on that object.
  4. Right-click the spot. "Welded."
  5. Points Mode off. Drag either object's handle there; the other follows.

The layer change between steps 2 and 3 is easy to forget, because a click only ever places a disc on the active layer. The next Phase 8 pass is meant to remove it: drop one handle on another and they weld.

A separate document, The Figures code, commented (docs/Figures-code.pdf), has every one of these files in full, with comments for reading and two actions traced end to end.

Shared pieces Figures relies on: interactor.js (handle dragging; see "Point Dragging"), drawLine in draw/drawUtilities.js (every line goes through it, which is how the transform reaches every object), buildParameterControls(), and each registry object's infrastructure() and, for Break apart, decompose().

Known gaps today

  • Nothing is saved: closing a figure subtab or reloading the page loses it (Phase 10). There is no undo (see "Undo in Figures: a proposal" under Design Notes).
  • The weld mark (a +) is hidden under the handle dot whenever a weld sits on a handle, which is nearly always; you see only its white ring.
  • A right-press on the centroid diamond (lines mode) starts a move; the same right-button fix made to handles and points mode has not been made there.
  • A weld moves its partners by shifting them. Turning a welded layer turns that layer; its partners are pulled along, not turned.
  • Objects without infrastructure() take only free discs.
