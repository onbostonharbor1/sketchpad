Patterns Tab — How It Works

Rewritten 27 October 2026 against the current code. The earlier page described a single patterns.js; the tab is now five files under ui/patterns/. Several of the old page's "discussion points" have been settled: script paths are rooted (/patterns/<category>/<file>.js), scripts run through the shared script runner, and the canvas is attached in one place.

Patterns browses the saved pattern scripts under /patterns/, one category frame per folder. Choosing one runs it on the shared canvas, with a thumbnail strip of its category and Prev/Next.

The files

FileOwns
patterns.jsPatternsTabSpec, PatternsController; init / restore / save; loading the manifest
patternsNav.jsthe subtab bar (Categories, and Pattern once one is chosen); the category view
patternsDisplay.jsrunning the chosen pattern, the thumbnail grid, Prev/Next
patternsMenuCmds.jscaption and menu (Help, Show Script, Notes, Create Thumbnail, Edit Manifest, Archive); the Commands panel
patternsState.jsthe current category and index

State

uiState.patterns = {
  activeCategory, activeItem,
  saved: { view: "categories" | "pattern", activeCategory, activeItem }
}

The rule the code follows: any action that changes what you are looking at writes uiState.patterns.saved first, then draws. Because saved is set during navigation, setUI.js uses restore() when you come back to the tab, and the tab returns to the same view. (setUI never calls save(); it is not needed.)

showSelectedPattern() also writes saved to the browser's session storage, and rehydratePatternsState() can read it back, but nothing calls that function at present, so a page reload still starts at Categories.

Two views

  • Categories: one frame per category, from manifest.getCategoryMap("patterns"). A click writes the new saved and shows the pattern.
  • Pattern: the pattern on the canvas in #sketchpad, its category's thumbnails in #action (the current one highlighted), and a caption with the title, Prev/Next and the menu.

Showing a pattern: showSelectedPattern(category, index)

  1. Write the module state, uiState.patterns and saved (and session storage).
  2. Clear #text, #action, #sketchpad.
  3. Run /patterns/<category>/<filename>.js with runScriptByPath() into #sketchpad, with controls enabled. An error is shown in red in its place.
  4. Draw the thumbnail grid, the caption, and make sure the Pattern subtab exists and is active.

Prev and Next wrap around at the ends of the category.

The manifest

ensurePatternsManifestLoaded() asks the shared manifest system for "patterns" (manifest.get), which reads the category list and each category's manifest.json into manifest.cache. Everything else reads it through manifest.getCategoryMap("patterns").

Commands panel

Rebuild & Validate asks the Node service to rebuild every manifest, clears the cache and marks every tab needsUpdate (syncSystemStateAfterRebuild), and redraws the current view from saved.

Small things worth knowing

  • Prev/Next on an empty category quietly does nothing (it reads an empty list rather than failing).
  • A restore that finds its category gone (after a rebuild) falls back to Categories; an index past the end is pulled back to the last item.
