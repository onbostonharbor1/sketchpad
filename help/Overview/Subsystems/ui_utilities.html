uiUtilities.js and the helpers that came out of it

Rewritten 31 October 2026. ui/uiUtilities.js used to hold every shared screen helper (this page keeps its old name so existing links still work). It now holds only clearDivs(). The rest moved to files named for what they do, and the code that used them now imports from those files.

clearDivs(extraId)

The one teardown every tab switch goes through (setUI.js calls it before every init and restore). In order:

  1. Goes down the table in regions.js: #action, #caption, #text, #sketchpad (and extraId, if given) are emptied and their display reset; #figure-sidebar is emptied and hidden; #interface-controls is emptied; #sketchpad-wrapper is hidden (a tab that draws must show it again).
  2. Removes everything in the permanent #button div tagged tab-extra: the per-tab additions such as Create Figure and Points Mode. (CLAUDE.md: anything a tab adds to #button must carry this class.)
  3. Clears every canvas overlay layer (canvasLayerManager.clearAll()) and the main canvas.
  4. Disarms the interactor (disarmInteractor(), imported from interactor.js).

After a Rebuild & Validate (rebuildSync.js)

  • syncSystemStateAfterRebuild(): empties the whole manifest cache and sets needsUpdate on every tab, so each re-initializes the next time it is shown. The Commands panels use it.
  • formatRebuildReportShared(report): turns the Node service's rebuild report into the text the panels show.

The Commands button and its panel

  • setCommandsButtonLabel(label): the button's text ("Figures Commands").
  • setCommandsButtonHandler(onClick): what it does; replaces any earlier handler. Every tab uses this.
  • showOffcanvas({ title, buildBody | bodyHtml }): shows the permanent slide-in panel (#offcanvasPanel) with a title and either a function that fills the body (Commands panels, which then wire their buttons) or ready HTML. The panel slides in with a dimmed page behind it and closes on the X button, a click on the dimmed area, or Escape. Bootstrap is no longer involved: offcanvas.js does it, and the look is in css/offcanvas.css and css/base.css.
  • showPanel() shows the panel as it stands (for a caller that filled it in itself, such as Show Script); hideOffcanvas() closes it (used after Help buttons and after choosing a saved setting).

Thumbnails (thumbnails.js)

  • renderThumbnailGrid(targetId, items, buildSrc, onClick): a grid of img.thumb-image in a .thumb-panel (Patterns, Gallery).
  • markSelectedThumbnail(targetId, index): puts thumb-selected on one of them.
  • buildCanvasThumbnailBase64(canvas, w, h): crops a canvas to its drawn area and returns a small PNG, for Create Thumbnail and secondaries.

Where the pass-through names went

buildCategoryDescriptor is imported from categories.js and syncLayerToCanvas (formerly passed through as syncOverlayToCanvas) from canvasLayerManager.js. The old aliases showCommandsOffcanvas and showOffcanvasPanel are gone; everything calls showOffcanvas.
