uiUtilities.js — Shared Screen Helpers

Rewritten 27 October 2026. The file is now ui/uiUtilities.js (it was ui_utilities.js; this page keeps its old name so existing links still work). The three overlapping offcanvas functions the earlier page complained about are now one, with two old names kept as aliases; the help-manifest loader has moved to help.js; canvas layers are cleared through canvasLayerManager.js.

A collection of helpers every tab uses: clearing the screen between tabs, the Commands button and its slide-in panel, thumbnail grids, and the two clean-ups that follow a Rebuild & Validate.

clearDivs(extraId)

The one teardown every tab switch goes through (setUI.js calls it before every init and restore). In order:

  1. Empties #action, #caption, #text, #sketchpad (and extraId, if given) and resets their display.
  2. Empties and hides the Figures layer strip (#figure-sidebar).
  3. Removes everything in the permanent #button div tagged tab-extra: the per-tab additions such as Create Figure and Points Mode. (CLAUDE.md: anything a tab adds to #button must carry this class.)
  4. Empties #interface-controls.
  5. Hides #sketchpad-wrapper: a tab that draws must show it again.
  6. Clears every canvas overlay layer (canvasLayerManager.clearAll()) and the main canvas.
  7. Disarms the interactor.

After a Rebuild & Validate

  • syncSystemStateAfterRebuild(): empties the whole manifest cache and sets needsUpdate on every tab, so each re-initializes the next time it is shown. This is the one the Commands panels use.
  • rebuildAllSystemCaches(): empties the cache, reloads every known manifest at once, resets Home's grouping, and deletes every tab's saved. Nothing calls it at present.

The Commands button and its panel

  • setCommandsButtonLabel(label): the button's text ("Figures Commands").
  • setCommandsButtonHandler(onClick): what it does; replaces any earlier handler. Every tab uses this one.
  • setCommandsButton(label, onClick): an older way that replaces the button element itself; not used.
  • showOffcanvas({ title, buildBody | bodyHtml }): shows the permanent slide-in panel (#offcanvasPanel, Bootstrap) with a title and either a function that fills the body (Commands panels, which then wire their buttons) or ready HTML. showCommandsOffcanvas and showOffcanvasPanel are the old names, kept as aliases.
  • formatRebuildReportShared(report): turns the Node service's rebuild report into the text the panels show.

Thumbnails

  • renderThumbnailGrid(targetId, items, buildSrc, onClick): a grid of img.thumb-image in a .thumb-panel (Patterns, Gallery).
  • markSelectedThumbnail(targetId, index): puts thumb-selected on one of them.
  • buildCanvasThumbnailBase64(canvas, w, h): crops a canvas to its drawn area and returns a small PNG, for Create Thumbnail and secondaries.

Passed through from elsewhere

  • buildCategoryDescriptor, from categories.js.
  • syncOverlayToCanvas(name, canvas), which is syncLayerToCanvas from canvasLayerManager.js: sizes an overlay canvas to match the drawing canvas.
  • escapeHtml(text): makes text safe to put into HTML.
