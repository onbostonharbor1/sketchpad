overlay.js — Help, Notes and Panel Overlays

Rewritten 27 October 2026 against the current code. The canvas layers (interaction, bbox, nodes, guides) that the earlier page described here have moved to canvasLayerManager.js. This file now handles only the panel overlays, and it has gained the Notes popup and an Edit button on help pages.

A panel overlay is an HTML panel shown over the app: a help page, a form, a debug panel, a file's notes. They all appear in one floating container (#overlayContainer, with a title bar and a close button) and take turns using it.

overlayManager

A small object (also on window.overlayManager for older code) with a list of named panels:

MethodDoes
register(name, element)adds a panel under a name
show(name, html)fills the panel and shows it. Also disarms the interactor, so handles cannot be dragged under an open overlay.
hide(name)hides it, keeping its contents
clearLayer(name)empties and hides one panel
clearAll()empties and hides every panel (not the canvas layers)

Unknown names throw.

initOverlay()

Called once at start-up (setUI.js). Registers #overlay-help, #overlay-forms and #overlay-debug as "help", "forms" and "debug", and wires the close button: it removes any per-overlay sizing from the panel, hides the container, and clears every panel. Missing elements throw at start-up.

Help pages: showHelpOverlay(helpPath, titleText, options)

  • Fetches the page; a failed fetch throws with the status.
  • Keeps only the page's <body> and shows it in the "help" panel, under a toolbar.
  • The overlay's title is the page's own <title>; failing that, titleText; failing that, the file name.
  • The toolbar has an Edit button (unless allowEdit: false) that opens the page in the TinyMCE editor (helpEditor.js, loaded the first time a page is edited).
  • With createIfMissing: true it skips the fetch and opens an empty editor, for writing a page that does not exist yet.

Notes: showNotesOverlay(titleText, notesText, actions)

The Notes item in a caption menu shows a source file's header comments here, in the same panel and style as help. actions become toolbar buttons (Show Script, Open in VS Code); a button's handler may return a message, which is shown in a status line. closeNotesOverlay() closes it.

Small helpers

showHelp(text) and hideHelp() show or hide a short text in the help panel. openOverlay(html) and closeOverlay() are older names for the same thing.
