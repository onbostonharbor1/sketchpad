menuManager.js — The Caption Menu

Rewritten 27 October 2026 against the current code. The Help-item builder the earlier page described has moved to help.js (menuManager still offers it under the same name), it now walks a nested help manifest, and a missing page gives a "Create Help" item instead of a grayed one. The unused imports the old page pointed out are gone. Tooltips are new.

menuManager shows the small drop-down that opens from a caption bar's "v" button. It shows whatever list it is given; each tab decides what is in its menu.

Using it

menuManager.open(items, anchorElement)

items: [ { label, onClick, disabled?, tooltip? }, ... ]

Tabs build their menu fresh every time "v" is pressed, so an item's enabled state is always current. Most items come from small makers in menuCmds.js: makeHelpItem, makeNotesItem, makeShowScriptItem, makeEditManifestItem, makeArchiveItem, makeThumbnailItem.

What open() does

  1. Refuses to run before initMenuManager() (called once by setUI.js at start-up).
  2. Checks the list: an array; every item has a string label; every enabled item has an onClick. A bad list throws rather than drawing a broken menu.
  3. Closes any menu already open: there is only ever one.
  4. Builds a div.caption-menu with one div.caption-menu-item per item; a disabled item gets the disabled class and no click; tooltip becomes the hover text. Clicking an enabled item closes the menu, then runs it.
  5. Adds it to #wrapper, 4 px below the anchor.
  6. Closes on a press outside it (other than on the anchor) or on Escape; both listeners are removed when it closes.

The object

menuManager = { open, close, clear, createMenuItem, buildHelpItem, isReady }. clear is another name for close; createMenuItem(label, onClick, disabled) makes one item.

The Help item: buildHelpItem(tabName, helpKey, options)

Lives in help.js. It reads /help/manifest.json (once, then cached), which is a nested object: tab, then subfolders, then a list of page names. It walks down [tabName, ...options.subdirs] (or options.path) and looks for helpKey in the list it reaches.

  • Found: a Help item that opens /help/<tab>/<subdirs>/<helpKey>.html in the help overlay.
  • Not found: a Create Help item that opens an empty editor for that path.

makeHelpItem(tab, key) in menuCmds.js wraps this, and gives a grayed "Help" when there is no key at all (Figures, for instance, passes none yet).

The help manifest is written by node/generateHelpManifest.mjs, which scans /help.
