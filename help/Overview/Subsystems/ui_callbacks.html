ui_callbacks.js — Retired

Checked 27 October 2026: ui_callbacks.js no longer exists in the code. This page is kept so that links to it still lead somewhere; it records what the file was and what replaced it.

ui_callbacks.js was an early routing layer: one place where generic events (a tab activated, a category or item chosen, a parameter changed, Prev/Next, Save, Reset) were forwarded to the right tab by name. Its own header called it "no orchestrators", but it did orchestrate: tab activation called each tab's init directly.

What replaced it

The old callbackNow
onTabActivatedsetUI.js and each tab's TabSpec (init, restore)
onCategorySelected, onItemSelectedeach tab builds its category list with an onClick per item (categories.js renders it)
onParamChangedthe parameter controls call the tab's redrawHandler and onParamChange directly (ui/controls/)
onPrev, onNextpassed to the caption bar per tab (caption.js)
onSave, onResetParameterscaption menu items built by each tab
onHelpRequested, overlay open/closeoverlay.js and help.js

The lesson the old page drew still holds: a second routing layer beside the tabs drifts out of step with them. The current design keeps routing inside each tab.
