Other Source Files — A Short Guide

Written 14 November 2026. These are the source files no other page in this Overview names. Each has a header or function comments of its own, and the function dictionary (docs/FUNCTIONS.md) lists every function.

Classes (classes/)

FileWhat it is
curveStitchClass.jsCurveStitch, the data container for the most common curve-stitch drawing: midpoint, radius, number of nodes and steps, colour, width, scales, rotation. Draw registry objects build one in init() and hand it to a draw function.
ellipseClass.jsEllipse and its mode constants (START_END, FULL, TAPER, START_TAPER, END_TAPER): the parameters for drawings made around an ellipse, read by draw/drawEllipse.js. (Its header still says drawEllipse.js.)
radiate.jsRadiate, the container for the Radiate object (drawRegistry/radiate.js): start, end and radial point, steps, colour.
overlayClass.jsNot an overlay class yet. It is a byte-for-byte copy of linkedCircles.js, imported by main.js and drawMain.js only for its side effect. Its own header says so. Worth deciding: make it real or drop the import.

Drawing (draw/)

FileWhat it is
drawEllipse.jsThe engine that draws ellipse-based patterns (renderPattern, drawInEllipse) and pointAtArcLength, which createNodes.js uses. Everything goes through drawLine.
drawPursuit.jsdrawRabbitPursuitCurve: the fox always runs towards where the rabbit is now, and its path is drawn step by step.
drawSpirals.jsThe spiral functions: Euler, Fermat, logarithmic, pure (three kinds) and Theodorus. Its header lists them. (The Ideabook pursuit engine, gallery/Ideabook/scripts/pursuitEngine.js, is a separate, later piece.)

Draw tab (ui/draw/) and the script view

FileWhat it is
drawExport.jsDraw's two export requests to the Node service: Create Gallery PNG and Create Pattern script. Both rebuild the lists afterwards (rebuildAllManifests).
drawInstance.jsMakes a private copy of a Draw registry object (Object.create(entry) with a cloned params) every time one is opened, so Draw, Figures and Patterns no longer share one set of settings.
../scriptView.jsshowScriptOffcanvas(path, title): shows a script's source in the side panel (Show Script).

Parameter controls (ui/controls/)

FileWhat it is
shared/constants.jsWIDGET_TYPES and the control class names. POINT_PICKER and POINT_PICKER_ARRAY stay in the list, but the renderer no longer builds them (handles are dragged on the canvas).
shared/helpers.jsSmall helpers for the point-picker dots. Only used if the point-picker widgets come back.
widgets/buttonWidget.jssetButtonControl: a button control that runs a named action.
widgets/numberWidget.jssetNumberControl: a plain number box that updates the parameter, redraws, and enforces min and max.
widgets/hiddenWidget.jssetHiddenControl: no screen control at all. It exists so a parameter can be declared without showing it.

Node service and tools (node/)

FileWhat it is
check_ports.mjsRun first by npm run check:ports (before start:sketchpad and dev:sketchpad): if port 5173 or 5174 is already in use it says so and stops the start. The service itself also stops with a plain message if its port is taken.
createFigureService.mjsThe older createFigure request, which writes a generated .js script. Figures now saves .json data through saveFigure instead; retire this when the older Create Figure feature goes.
makeHelpPdf.mjsnpm run help:pdf -- file.pdf: one PDF of the Overview and Tutorials, printed by a browser from the running app.
