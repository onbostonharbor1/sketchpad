categories.js implements Sketchpad’s universal category rendering system. It is a pure DOM builder that renders category frames from a single, tab-supplied descriptor format. It has zero knowledge of manifests, tabs, Patterns, Gallery, Draw, or any other subsystem.

The calling tab is responsible for all data decisions (grouping, titles, item order, handlers). This module only validates the descriptor structure (fail-fast) and renders what it is given.

Descriptor format (required)

renderCategories() expects a descriptor array of category-frame objects: 

[
  {
    title: "Category Name",
    items: [
      {
        name: "Item Name",
        onClick: function,     // required
        hasSubitems: boolean   // optional
      },
      ...
    ]
  },
  ...
]

Each descriptor entry corresponds to one rendered “category frame” with a header and a list of clickable items.

renderCategories(targetId, descriptor)

This is the main entry point. It clears a target container and renders a complete category UI into it.

Arguments:

  • targetId – DOM id of the container (for example, "text")
  • descriptor – array of category frame descriptors (see format above)

Fail-fast behavior:

  • Throws if targetId does not exist in the DOM
  • Throws if descriptor is not an array
  • Throws if any frame descriptor is not an object
  • Throws if frame.items exists but is not an array
  • Throws if any item lacks name:string or onClick:function

Rendering sequence (high-level):

  1. Clears the target container.
  2. Creates an outer wrapper: <div id="categories">.
  3. Sorts category frames by title (case-insensitive).
  4. For each category frame:
    • Builds the frame DOM (header + content).
    • Optionally sorts items by name (case-insensitive).
    • Builds each item DOM and wires its click handler.

Category item click behavior:

  • Marks the clicked item as active via setActiveItem(targetId, itemName).
  • Invokes the caller-supplied itemDesc.onClick() action.

Sorting behavior:

  • Category frames are always sorted by frameDesc.title.
  • Items are sorted by default, unless the frame descriptor explicitly sets:
    sortItems: false

setActiveItem(targetId, itemKey)

This function updates visual state after a click. It finds all elements with class .item inside the target container and applies:

  • .active to the clicked item
  • removes .active from all other items

It is fail-fast: it throws if the target container cannot be found.

DOM-building helpers (private)

  • buildCategoryFrameElement(title, count)
    Builds the outer frame structure: 

    <div class="category-frame">
  <div class="category-header">Title (count)</div>
  <div class="category-content"></div>
</div>

    The header text includes an item count suffix like (12) when count is numeric.

  • buildCategoryItemElement(name, hasSubitems)
    Builds an item row: 

    <div class="item">
  <span>name</span>
  <!-- optional chevron icon -->
</div>

    If hasSubitems is truthy, a Bootstrap icon chevron is appended: <i class="bi bi-chevron-right"></i>.

Utility functions

  • clearCategoryFrame(targetId)
    Clears the target container by setting innerHTML = "". This function does not throw if the container is missing.

  • buildCategoryFrame(targetId)
    Clears the target container, creates the outer #categories wrapper, appends it, and returns the wrapper element. This is rarely used because renderCategories() normally performs this work.

    This function is fail-fast and throws if the target container is missing.

Overall, categories.js is the “universal renderer” for category-style UIs in Sketchpad. Tabs provide a descriptor that defines what to show and what happens on click. This module validates the structure and renders it consistently, deterministically, and fail-fast.
