Inverse Star

Inverse Star allows you to create star shapes with concave points. This tool is useful for creating unique star designs that have inward-pointing vertices.

In the future, the parabolas will be separable from the midpoint, but each by the same amount.

How to Use the Inverse Star Tool

  1. Select the Inverse Star from Categories.
  2. Use the controls on the left to change the shape of the inverse star.
